# CSS Animation Challenge

## Project Description
This project is a CSS animation challenge built using
HTML and CSS.

The aim of this challenge was to create an interactive webpage
based on a provided wireframe, using CSS animations and
transitions to enhance user interaction and visual appeal.

## Features
- Animated navigation links with hover effects
- Hero section with slider arrows
- Featured image with zoom and overlay effects
- Animated Read More button
- Sponsors section with hover animations
- Contact form with input focus effects
- Smooth page scrolling
- Fade-in animations on page load
- CSS transitions and keyframe animations

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Transitions
- CSS Transforms
- CSS Keyframes

## How to Run
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Hover over navigation links, images, and buttons to test animations.
5. Scroll through the webpage to explore the different sections.
